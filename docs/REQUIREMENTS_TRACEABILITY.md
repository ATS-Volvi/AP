## 2. Actors on Stage
| Actor | Title | Domain Responsibilities |
| :--- | :--- | :--- |
| **AP Clerk** | Handles the Invoice | Logs documents, initial data verification, scans, classification review, vendor contact. |
| **AP Controller** | Owns the Process | Resolves exceptions, oversees match tolerances, signs off overrides, configuration publication. |
| **Buyer / Procurement** | Placed the Order | Commercial agreement authority, purchase orders, price variance clarifications. |
| **Warehouse** | Took Delivery | Confirms physical receipt condition, quantity, logs Goods Receipts (GR). |
| **Budget Owner** | Signs it Off | Cost-centre / project manager approving departmental financial expenditure. |
| **Finance Director** | Releases the Cash | Cash management, payment runs, high-value threshold approvals, out-of-cycle payments. |
| **Vendor** | Sent the Invoice | External trade partner supplying goods/services, issues credit notes, resolves disputes. |
| **Bank** | Moves the Money | Settlement execution, statement feed, payment confirmation authority. |
| **Customs Broker** | Clears the Border | Import VAT, customs duties for non-EU consignments (solar components from Asia). |
| **Auditor / Tax Authority** | Checks the Trail | Audit inspections, Dutch Belastingdienst compliance, VAT/BTW verification. |
